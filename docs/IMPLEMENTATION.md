# Implementation milestones

1. Foundation: Next.js/TypeScript and FastAPI/SQLModel with locked dependencies.
2. Persistence: transactional lead/discussion API, validation, explicit seed command.
3. Workspace: accessible single-screen lead list and dialogs.
4. Follow-ups: local-time grouping, combined filters, responsive presentation.
5. Verification: API, UI logic, browser flows, accessibility, Docker persistence.
6. Delivery: reproducible setup, screenshots, walkthrough, disclosure, public repository.

The agreed scope is a single-user local demonstration. No authentication, hosted deployment,
external notifications, or in-product AI is required. UTC is the storage/API time standard;
the viewer's browser timezone defines today.
